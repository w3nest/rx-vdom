# Tutorials

Our tutorials are designed to help you get up to speed with {{rx-vdom}} quickly, offering hands-on experiences 
through interactive notebooks.

<note level="hint">
These tutorials allow you to explore the framework in action by modifying and running code snippets dynamically
(powered by the <ext-link target="mkdocsTS">mkdocs-ts</ext-link> library). 
While your changes will not be persisted after the session ends, the environment is perfect for rapid testing 
and experimentation.

Also, keep in mind that you toggle a side-by-side view of the API documentation, numerous links are proposed in the 
tutorials, using the <i class='fas fa-columns rounded border p-1'></i> button in the right-hand navigation panel. 
</note>

In the tutorials, you will gain a deeper understanding of {{rx-vdom}}'s core concepts, best practices, and how to 
integrate them into real-world applications. 

The following tutorials are proposed:

- **[Getting Started](@nav/tutorials/basics)**: This tutorial provides a solid overview of {{rx-vdom}}, covering its 
  setup, basic components, and key features. It’s ideal for beginners who want to understand the foundational concepts
  of reactive programming and how they’re implemented in the framework.

- **[To-Do App](@nav/tutorials/todo)**: Dive deeper with a real-world example! This tutorial walks you through building
   a simple To-Do application, demonstrating how to structure your project and apply best practices in reactive design. 
   You'll learn how to manage state, handle user interactions, and effectively use {{rx-vdom}} to create
   dynamic interfaces.


We are always looking for ways to improve! If you have ideas for additional tutorials or want to suggest other topics,
feel free to open an issue on the <github-link target="rx-vdom">GitHub repository</github-link>.

<note level="warning" title='Reactive Programming'>
While this tutorial focuses primarily on the {{rx-vdom}} library itself and how it connects to observable principles,
it's worth noting that {{rx-vdom}} is built on reactive programming concepts.
If you're new to reactive programming, don't worry—you can still follow the tutorials without an in-depth 
understanding of the paradigm. The examples are designed to be approachable, and you'll gradually become more familiar 
with reactive principles as you work through the material.

That said, if you find yourself intrigued and eager to explore more about reactive programming, we encourage you to 
dive deeper into the topic in a second step. 
Mastering the reactive programming paradigm will not only significantly enhance your understanding of {{rx-vdom}},
but can also transform the way you approach programming—whether in UI development or beyond. 

For comprehensive resources on reactive programming, check out the documentation on 
<ext-link target="learnRxJS">Learn RxJS</ext-link> and other tutorials available online.
</note>
