# @rx-vdom/todo-app-js

Simple example of a TODO application in JavaScript. 
It serves as illustration of `rx-vdom` usage.
The application is available online [here](https://w3nest.org/apps/@rx-vdom/todo-app-js/latest).

You can load the application in your computer by opening `index.html` in your web-browser.

The project aims at reproducing the
<a href='https://codesandbox.io/s/github/vuejs/vuejs.org/tree/master/src/v2/examples/vue-20-todomvc?from-embed'>
todos example of Vue</a>.
